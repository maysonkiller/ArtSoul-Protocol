## Reproduce the release checks

Run from the repository root with the pinned dependency lock. The linked runbooks identify the required private register, verified archive, browser engines or read-only RPCs. Keep private evidence outside public source control.

```sh
npm run build
npm run test:unit
npm run test:contracts
node scripts/ordinary-audit-manifest.cjs --payout --rebuild docs/security/C12_ORDINARY_PAYOUT_MANIFEST.json <trusted-solc-0.8.24>
node --test test/treasury-safe-preflight.test.mjs test/ordinary-outbid-refund.test.mjs test/collection-phase-lock.test.mjs
node --test test/verify-genesis-grants.test.mjs test/genesis-metadata-preflight.test.mjs test/indexer-health-monitor.test.mjs
node --test test/banner-terms-review.test.mjs test/storage-recovery.test.mjs test/indexer-reorg-atomicity.test.cjs

```
