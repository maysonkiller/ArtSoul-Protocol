# ArtSoul Public Progress Report — 2026-07-22 to 2026-07-28

Audience: Base ecosystem and public build-in-public followers.

Status boundary: this report covers 27 pull requests merged to `main` during
the first unreported window after the 2026-07-21 report. It includes recorded
production verification, excludes unmerged work and canon-only edits, and does
not describe an open acceptance gate as complete.

## What shipped

### Fail-closed Base Sepolia indexing

- Event-processing failures now remain visible as failed or dead work. An
  incomplete event range cannot advance the indexer cursor, and previously
  completed events remain idempotent when the range is retried.
- The indexer heartbeat can now stop promptly instead of holding a database
  connection for the remainder of a 30-second sleep.
- Event-processing leases are committed before projection work and fenced by
  worker and attempt identity, allowing heartbeats and the stale-work reaper to
  observe active processing without letting an old attempt overwrite a newer
  one.
- Post-deploy checks recorded a healthy Base Sepolia indexer, an advancing
  cursor, zero unresolved, failed or dead events, and no stale processing rows
  after the lease and reaper window.

### Clearer and safer operations

- Removed a dormant alert path and false placeholder throughput fields.
  Indexer health now reports maintained rolling RPC latency and error data.
- Removed the public fallback credential for Prometheus metrics, required an
  explicit credential before startup, and bound the endpoint to loopback only.
  Production checks confirmed unauthenticated requests were rejected and the
  Base Sepolia monitor remained healthy.
- Restored reproducible clean installs by completing the lockfile's
  auto-installed peer metadata and documenting the npm version already pinned
  in CI.
- Accepted a seven-day infrastructure cost window. Observed RPC and database
  usage remained within the configured controls, the Supabase Spend Cap stayed
  enabled, and the documented manual review cadence remains active.

### Mobile wallet and sign-in hardening

- Added a safe mobile acceptance bench that exercises the production sign-in
  wrapper plus negative upload-policy checks without uploading a file, creating
  a storage object or sending an on-chain transaction.
- Rejected stale WalletConnect session topics instead of publishing a cached
  connected state, and allowed a restored live session to continue to sign-in
  on the next explicit user action.
- Corrected the MetaMask `personal_sign` message encoding, required the session
  permissions used by sign-in and transactions, isolated ArtSoul's external
  mobile session store, and routed required signed methods through the
  authoritative WalletConnect session after permission checks.
- Base Sepolia remains the only product write network. The production
  real-phone sign-in acceptance is still open, so this report does not claim
  that the remaining A1 gate is complete.

### Controlled-beta readiness

- Added tester and operator checklists, a structured issue form, a redacted
  fallback report template, prototype-deviation disclosures, pause criteria and
  an evidence-based go/no-go record.
- The materials are prepared, but the recorded decision remains **NO-GO** until
  every Phase A gate has evidence and no P1 issue is open.

### Base product commitments

- Updated the homepage to state the demand-before-minting value proposition and
  explain the compact publish, build collector demand, settle and mint path.
- Added cached, reorg-safe public metrics for artists, completed auctions,
  unique collectors and settled volume without adding page-view RPC fan-out.
- Removed stale active-network copy so Base Sepolia is the only product
  testnet and Base remains the production chain.
- Reconciled the production acceptance evidence after correcting the
  asynchronous module-entry race found during deployment verification.

## Validation evidence

- The merge-reconciled Node suite passed with zero failures on Ubuntu and
  Windows.
- The 19-contract test suite passed.
- GitHub CI passed on Ubuntu and Windows, and the Vercel preview check passed.
- Runtime-heavy indexer changes also included PostgreSQL 17 integration
  coverage and focused production-host verification before their backlog items
  were accepted.
