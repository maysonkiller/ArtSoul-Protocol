# Account-menu identity marks

These unmodified files are copied from `docs/design/study-assets`, whose source
record was verified on November 1, 2026. They identify the actual network,
currency or connected wallet; they do not imply a partnership or endorsement.

| File | Official source |
| --- | --- |
| `base.svg` | `1_Base Brand Assets/The Square/Base_square_blue.svg` in the [Base brand download](https://brand.base.org/base-brand.zip) |
| `eth.png` | [Ethereum diamond](https://ethereum.org/_next/static/media/eth-diamond-black.31u_5ih2w7osr.png), linked from [Ethereum assets](https://ethereum.org/assets) |
| `rabby.png` | [Rabby favicon](https://rabby.io/assets/images/favicon.png), linked from [Rabby](https://rabby.io/) |

The production account menu loads these files locally. Rabby appears only when
the active provider explicitly identifies itself as Rabby. Unidentified wallet
providers have no brand row; no cached selection or demo identity is substituted.
Brand colors belong to the source marks; ArtSoul's theme palettes are unchanged.
