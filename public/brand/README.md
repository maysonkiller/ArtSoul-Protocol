# Account-menu identity marks

These unmodified assets identify the network, currency or connected wallet.
The original Base, Ethereum and Rabby files are also recorded in
`docs/design/study-assets`. The MetaMask PNG comes from the extension source.

| File | Official source |
| --- | --- |
| `base.svg` | `1_Base Brand Assets/The Square/Base_square_blue.svg` in the [Base brand download](https://brand.base.org/base-brand.zip) |
| `eth.png` | [Ethereum diamond](https://ethereum.org/_next/static/media/eth-diamond-black.31u_5ih2w7osr.png), linked from [Ethereum assets](https://ethereum.org/assets) |
| `rabby.png` | [Rabby favicon](https://rabby.io/assets/images/favicon.png), linked from [Rabby](https://rabby.io/) |
| `metamask.png` | [MetaMask extension icon](https://github.com/MetaMask/metamask-extension/blob/f975c3d4a0d9c592d8b6afb8630bb399de7db505/app/images/icon-64.png) |

The account menu uses local marks for identified Rabby and MetaMask sessions.
Other injected wallets can supply their own embedded icon through EIP-6963.
The menu matches the announcement to the active provider object. Unidentified
wallets have no logo.
Brand colors belong to the source marks; ArtSoul's theme palettes are unchanged.
